# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

**Inercia** — a singleplayer browser prototype (phase F0 of a larger plan) used to validate movement, cards and procedural maps before porting to Godot. The whole game lives in one file, `index.html` (inline CSS + one `'use strict'` script, vanilla JS, Canvas 2D + WebGL). No build step, no dependencies, no package manager, no tests, no linter. Code comments, UI strings and the README are in Spanish; keep new ones in Spanish.

Design-decision IDs like `D-03`, `D-04`, `D-07` and phases like `F3` refer to the external plan document (not in this repo); keep those references when touching related code.

`docs/integracion-mecanicas.md` holds the agreed plan (design pillars, the "no mechanic sets your velocity" rule, the chain economy for cards, and implementation phases 1–5). Read it before changing cards, planets or the chain/bar economy, and keep it updated when a phase lands. Phase 1 (telemetry) lives in the `// ---------- telemetría ----------` section: per-level counters in `G.tel` (fed from `update`, `launch`, `gainChain`, `castCard` and `hurt(sx, sy, force, cause)`, which always takes a cause string), `record(won)` stores one entry in `localStorage` (`inercia.tel`) with an `econ` field for A/B comparisons, and `showMsg(..., r)` renders the stats and the 1–5 rating. The next level's seed is derived from the current one (`mulberry32(seed)`), so a starting seed reproduces the whole sequence.

## Running and deploying

- Run: open `index.html` directly in a browser, or serve the folder (e.g. `python3 -m http.server`) — test on desktop and on a phone in landscape.
- Debug: chunk shape is validated at load with `console.assert` ("chunk mal formado") — check the console after editing maps.
- Deploy: every push to `main` runs `.github/workflows/pages.yml`, which copies **only** `index.html`, `manifest.webmanifest`, `icon.svg` and `musica.mp3` to GitHub Pages (https://alex-alas.github.io/multiplayuh/). Any new asset file must be added to the `cp` line in that workflow.

## Architecture of `index.html` (sections marked `// ---------- ... ----------`)

- **`CFG`** at the top of the script: all calibration knobs (gravity, launch power, charges, hover fade, kill speeds, etc.). Tune gameplay here rather than hardcoding values.
- **Chunks / map generation**: levels are hand-made 16×16 ASCII chunks (`START`, `MID[]` for the air, `GROUND[]` for the bottom row, `CH` = 16). Design rule: **no solid surfaces in the air** — only planets; solid tiles live in the bottom 3 rows of `START`/`GROUND`. Legend is in the comment above them (`#` solid, `=` safe tile, `B` bouncy, `^` spikes, `P`/`p` big/small planet center candidate, `?` random enemy, `W/F/S/T` enemies, `*` orb that may carry a power-up, `N` possible core spot, `@` cannon start). Invariant (asserted): every chunk is 16×16, `START` has `@`, every other chunk has exactly one `N`, `MID` has no `#=B^`, solids only in the last 3 rows, planet centers within columns/rows 2–13. `genLevel(seed, lvl)` lays chunks in a 2D grid, wider than tall, that grows with the level (`CFG.map`: 16×8 → +2 cols/+1 row per level → 24×12): `MID` above, `GROUND` on the bottom row with `START` somewhere in it, wrapped in a 1-tile solid border (`G.W`/`G.H` include it; `tileAt` treats out-of-bounds as solid). First pass collects planet candidates; in shuffled order a planet survives only if it doesn't touch a solid tile and its surface is ≥ `CFG.planetGap` (2 max-power launches) from every kept one. Then W/S/T placed in the air snap to the nearest planet (`onPlanet`, they walk by angle via `sit()`) or become flyers. Common orbs are never written in chunks: each chunk gets 0 (`CFG.orbs.empty`) or 1–3 clusters of 1–6 orbs with gaussian spread, kept ≥ 22 px apart via a cell grid and away from solids, planets and the cannon. Each planet adds orbiting orbs (`o.pl`) and, by level, a surface enemy; loose objects are pushed out of planets with `clearOf`. `N` spots are shuffled and up to `min(8, 3 + lvl)` at ≥ `CFG.coreGap` from each other become `L.cores`. From level 2 a mini-boss (elite flyer, `boss: true`, `hp: 3`) guards and shields the first core. There is intentionally no reachability validator (see the `ponytail:` comment).
- **Movement bar**: the main resource. `launchVec` computes cost (`launchBase + launchPow × power`, scaled by passive mods) and clamps power to the remaining bar; while `G.cannon` is true the first launch is free and full power, the player doesn't move and is invisible/invincible (`hid` in `update`: enemies don't detect, shoot or hurt them). Hover drains bar over time up to `hoverMax`. Refills: orbs (small), cores, kills (fraction by style rank, `CFG.rankRefill`), and safe `=` tiles (up to `CFG.padCap`). **Chains** (`P.chain`, max `CFG.chainMax`) are the core loop: every orb, kill or core calls `gainChain()` (+1 chain and a short hit-stop `G.stop`); a launch with a chain is free and hover doesn't drain bar. Style (`G.style`, 100 per rank D–S) also boosts launch power and max speed (`boost()`). "Move or die": `P.cold` fills below `coldSpeed`; full = hurt. Safe zones (`P.safe`: resting on a planet or on `=`) drain cold instead. Levels end when every core is destroyed (`win()`).
- **Orbs**: the chain link and lowest-tier "enemy". `takeOrb()` gives a chain, a little bar, style and combo, and slows the player via `CFG.orbDrag`: drag grows with slowness² (≈5 % at ≥1600 px/s, 35 % at ≤400) and below that it also deflects off the orb's normal weighted by slowness³.
- **Audio**: `musica.mp3` loops through a WebAudio lowpass (`lp`) that `audioTick()` closes in menus/cannon, opens in play, dips on damage, and `playbackRate` .8 during tiempo bala. Under `file://` the element plays unrouted (no filter). SFX are synthesized (`tone`/`noise`, table `SFX`, called via `sfx(name)`), no files. The context starts on the first pointer/key event; music and SFX toggles persist as `inercia.audio`.
- **Passives (`PASSIVES`)**: one optional slot (`inercia.passive`). Each is a partial override of `MODS`; `world()` merges them into the global `M`, and gameplay code reads multipliers from `M` rather than checking passive ids.
- **Cards (`CARDS`)**: card definition is kept separate from how cards are acquired (D-07). Each card has `n`, `d`, `cd`, optional `aim: 1` (receives a unit direction `ux, uy`), and `cast()`; returning `false` from `cast` means it failed and shouldn't go on cooldown. The player's 3-card build is persisted in `localStorage` (`inercia.build`, also `inercia.inv`) via the `load`/`save` helpers.
- **State**: globals `state` (`'menu'`/`'play'`/…), `G` (world: grid, enemies, shots, fx, splats, time-slow, shake…) and `P` (player). `world()` creates both; `startLevel()` also resets the hand, camera and input.
- **Physics**: tile-based circle-vs-grid collision plus circle-vs-planet. `move(e, dt, grav, onHit, onRock, pulled)` applies planet gravity (`pull()`: toward each center inside its field `f`, falling off with 1/d and fading at the edge; it also scales down global gravity), substeps by speed (≤6 px per step), resolves X then Y via `hit()` and then pushes out of planets calling `onRock`. Callbacks: `playerHit`/`walkHit`/`flyHit` for tiles, `playerRock` (bounce above 320 px/s, otherwise land: `P.rock`, `P.grounded`, safe) and `flyRock` for planets. Planet params live in `CFG.planet`. Shots are curved by `pull()` too and die inside planets. `tileAt` treats out-of-bounds as solid.
- **Update**: fixed 60 Hz step (`STEP`) driven by an accumulator in `frame()`; "tiempo bala" (`G.slow`) scales the accumulator, not `dt`; hit-stop (`G.stop`) pauses it. Kill rule: colliding at ≥ `killSpeed` (tank and boss ≥ `tankSpeed`), or with parry/shield/stunned/marked enemies; otherwise the player takes damage. Lethal hits go through `strike(e)`, which removes 1 hp from multi-hp enemies (bosses) and only calls `kill(e)` on the last one.
- **Input**: Pointer Events for touch and mouse plus keyboard; slingshot on drag (left half on phone, right half with `CFG.swap`, persisted as `inercia.swap`; the card row and camera offset flip too), hover while aiming in the air, cards 1–3/Q/right-click on desktop.
- **Render**: the world is drawn crisp (no pixel art) to an offscreen buffer at screen resolution (`buf`, `k` = buffer px per CSS px, capped at 1.5; `ART` is just the base detail thickness), then a WebGL post-process (`VS`/`FS` shaders, `post()`) adds chromatic aberration scaled by speed/hits/time-slow and a damage glitch, plus scanlines/vignette/grain when the retro filter is on. Both effects can be turned off in the menu (`FX = {ca, retro}`, persisted as `inercia.fx`). There is no motion blur. Without WebGL the buffer is drawn with no post-process. HUD is drawn separately at full resolution (`hud()`), respecting `SAFE` insets.
- **Look**: fixed "riso" ink palette in `C` (bone, sunflower, tomato, teal, cobalt on night) with Jersey 10 + IBM Plex Mono fonts; reuse `C` colors rather than introducing new ones.
- **Menu / fullscreen**: menu renders over a demo map (`G.demo`) that the camera pans across. The camera is clamped to the map bounds. Fullscreen via the Fullscreen API (auto on Android when tapping Play, `F` on desktop); iOS has no Fullscreen API, so it relies on `manifest.webmanifest` (fullscreen + landscape) via "Add to Home Screen".
